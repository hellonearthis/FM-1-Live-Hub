## Overview
Built by **Animatek** on `fm1-base` + `Open303` (4× oversampled diode-ladder filter with soft-clipping output limiter), **ATEK303 v1.4** turns the FM-1 into a complete acid machine featuring:
- **14 WAVE Oscillators (`CC 79` or `ALGO` button):** `SAW`, `SAW+SUB`, `FAT`, `DETUNE+SUB`, `SHINE`, `METAL`, `GROWL`, `BREATH`, `WILD`, `OCTAVES`, `OCT UP`, `FIFTH UP`, `SQR+SUB`, `SQUARE`
- **4-Stage FX Chain:** `Voice → Drive (Off/OD/RAT/Fuzz) → Chorus/Flanger → Synced Ping-Pong Delay → Dattorro Plate Reverb`
- **64-Step Sequencer & 32 Presets:** Live acid pattern generator, per-layer mutation buttons, Piano Roll step editor (`EDIT`), and 32 full-state preset slots (12 factory presets).

## Exact MIDI In / Out Spec (From `atek303/app/app.c`)

### 1. MIDI CCs
ATEK303 responds directly to **7 MIDI CCs** plus `CC 123` (All Notes Off), and ignores MIDI Program Change (`0xC0`):

| MIDI CC | ATEK303 Parameter | FM-1 Live Hub (`CC Mode: ATEK303`) |
|---|---|---|
| **CC 74** | `Cutoff` | Mapped from `op2Level` |
| **CC 71** | `Resonance` | Mapped from `feedback` |
| **CC 75** | `Env Mod` | Mapped from `op3Level` |
| **CC 76** | `Decay` | Mapped from `op1Decay` |
| **CC 77** | `Accent` | Mapped from `op4Level` |
| **CC 78** | `Tuning` (Pitch) | **Locked at `64` (center)** so Drift, Snap FX & Roulette never detune pitch |
| **CC 79** | `Wave` (`1–14`) | Driven by the **Wave** selector in Section 2 (or `Auto` via Algorithm) |
| **CC 123** | All Notes Off | Sent automatically on Section 2B **Stop Sequence** |

### 2. MIDI Notes (Two Modes)
- **When ATEK303 Sequencer is STOPPED:** Incoming MIDI notes play the mono 303 voice directly. Velocity **`>= 100`** triggers a true 303 accent, and overlapping legato notes (`slide: true` in Section 2B) trigger true 303 slides.
- **When ATEK303 Sequencer is RUNNING:** Incoming MIDI notes **transpose the running acid line's root note** live (`set.root = note % 12`) — uncheck **`Send Seq Notes`** in Section 2B and use keys `A–K` or your MIDI keyboard to transpose ATEK303's own 64-step line in real time!

### 3. MIDI Clock & Sync
- Enable **`MIDI Clock (24 PPQN)`** in Section 2B to send Start (`0xFA`), 6 clock ticks per 16th step (`0xF8`), and Stop (`0xFC`). ATEK303's sequencer and synced delay lock automatically to Hub BPM (`OPTIONS > CLK OFFSET` defaults to `-16 ms`).

## Hardware Panel Controls
- **`PLAY`**: Start / stop internal or MIDI-clocked sequencer.
- **`SEQ`**: Generate a new pattern (while playing: queued for next bar). Hold **`OCT- + SEQ`** to toggle **LOCK** so `SEQ` mutates instead of replacing the seed.
- **`ENV` / `LFO` / `ARP`**: Mutate **Time**, **Octaves/Notes**, and **Slides/Accents** on the visible 16-step page.
- **`REC`**: **Undo** last mutation or step edit.
- **`EDIT`**: Cycles Piano Roll step editor → `SEQ` → `PATT` (`SELECT` moves step, key sets note + advances, `K1` semitone, `K2` octave, `K3` Acc/Slide, `K4` Gate).
- **`PRESETS` encoder**: Scroll 32 presets (queues `NEXT` at bar end while playing; `SEL` or white keys jump immediately).
- **`GLO` / `OCT- + HOME`**: **OPTIONS** (display theme, MIDI In/Out channels, `SEQ NOTES OUT`, `CLOCK OUT`, `CLK OFFSET`, fine tune).

*(Note: `fm1-live.exe v0.5.1` ignores `--map`; the Ch 16 panel buttons in Section 2B apply when using a `fm1-map`-enabled build or hardware controller.)*
